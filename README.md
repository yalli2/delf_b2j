# DELF B2 scolaire et junior (Le DELF B2 100% Réussite) — site interactif

국제학교 프랑스어 DELF 대비 수업용 인터랙티브 학습 사이트.

- **Main** (`index.html`): 교재의 모든 과(듣기·읽기·쓰기·말하기·모의고사)를 한눈에 보고 각 챕터로 이동, 챕터별 진도와 점수 표시
- **Chapitre** (`chapter.html?c=…`): 모든 연습문제를 바로 풀고 `정답 확인`으로 점수·해설 확인 (기록은 브라우저에 저장)
- 🔊 프랑스어 음성: 브라우저 음성 합성(Web Speech). 가장 자연스러운 발음은 **Microsoft Edge**의 *Denise / Henri / Vivienne (Natural)* 또는 **Chrome**의 *Google français* 음성 — 상단 「음성 설정」에서 선택
- 🎙 말하기: 준비/발표 타이머, 녹음·재생, 음성 인식(프랑스어 받아쓰기), 모범 답안 듣기, 자기평가 체크리스트
- 한국어 / English / Français 화면 전환

저작권 보호를 위해 교재의 지문·스크립트·예시는 모두 변형·재구성한 학습용 자료입니다 (교재 구성과 학습 목표만 참고).
